# Laptop / Server Setup

Modulares Setup-Script für Ubuntu-basierte Systeme. Unterstützt zwei Zielgeräte:

- **Laptop** — Desktop mit GPU (ComfyUI, TTS, Ollama, VSCode, BambuStudio)
- **Server** — Headless (Jellyfin, Immich, Navidrome, Radio-Ripper, FreshRSS, Dozzle)

Siehe [`setup.md`](setup.md) für Verwendung, Module und Konfiguration.
